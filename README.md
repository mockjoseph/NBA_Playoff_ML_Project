# NBA Playoff Predictor

### Overview
This project was completed in a data science course at Gonzaga University. Throughout the semester we learned about different ML algorithms with classification. Most algorithms used in this course were supervised learning algorithms where we learned how the context behind them, then for assignments we were asked to implement these in code. At the end of the course the class was asked to create their own classification projects using large datasets in categories they found interest in. James and I decided to do a project focusing on NBA teams making the playoffs. We were curious whether we could tune and use the algorithms that we implemented to make accurate classifications of teams making the NBA playoffs for any given season based on a number of factors.

### Learnings
In this project I learned a lot of different coding principles. Our instructors ensured we were not using outside libraries that would assist us (such as python pandas and sklearn). We were asked to build out the classes and methods within these packages ourselves to deepen our understanding of python coding principles and machine learning and data analysis as a whole. This project introduced me into data analysis through python and docker containers (where we used docker containers to ensure all students had access to the packages and environments that we were supposed to be working in). Prior to this project I was unfamiliar with using python in coding, but was able to learn the syntax, tricks to using it, and developed an appreciation for the language when it comes to data analysis and ML.
